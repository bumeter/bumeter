# Thiết kế lại giao diện — Kế hoạch triển khai (bản gọn)

> Người thực hiện: dùng superpowers:executing-plans hoặc superpowers:subagent-driven-development; mỗi task một commit, làm theo TDD.

- **Mục tiêu:** làm lại lớp giao diện theo spec: thẻ hiện đại, bo 4px, nút phẳng, bố cục theo độ rộng (3 cột / cột icon + ngăn kéo / 1 cột). Giữ nguyên logic và API.
- **Kiến trúc:** bộ token mới + component dùng chung trong `app/ui/src/components/`. `main.ts` gắn `data-layout` theo độ rộng cửa sổ, CSS đổi grid theo đó. Các view giữ cách lấy dữ liệu, chỉ đổi phần hiển thị.
- **Stack:** TypeScript thuần + `h()`, Vite, Vitest + happy-dom. Một thay đổi Rust nhỏ (`Config.theme`).
- **Spec:** `docs/superpowers/specs/2026-09-28-redesign-design.md`. **Mockup chuẩn: `docs/superpowers/specs/2026-09-28-redesign-mockups/design-v2.html`**. Nhánh: `feat/redesign` (tách từ `feat/skill-search`).
- **Skill khi làm:** `frontend-design` (token, component, từng màn), `dataviz` (biểu đồ, meter), `web-design-guidelines` (rà sau mỗi màn).

## Ràng buộc chung

- Bo góc `--r-sm: 3px`, `--r: 4px`, `--r-lg: 6px`. **Không gradient ở đâu cả.** Không bóng đổ cho nút/chip/thẻ; bóng chỉ cho ngăn kéo, hộp thoại, menu thả xuống.
- Màu nhấn xanh dương (`#007aff` sáng / `#0a84ff` tối). Màu công cụ lấy từ `SourceInfo.color` qua `--tc`.
- Mốc độ rộng: `wide` ≥ 1200px, `medium` 700–1199px, `narrow` < 700px.
- Mọi chữ hiển thị qua `t()` (vi + en) và `textContent`; không `innerHTML` với dữ liệu.
- Không thêm framework hay dependency cho UI. `prefers-reduced-motion` thì tắt chuyển động của ngăn kéo.

## Review Focus

1. **Đổi độ rộng khi ngăn kéo đang mở** (medium → wide): ngăn kéo tự đóng, chi tiết hiện ở cột phải, không mount chi tiết hai lần. Test thuộc Task 4.
2. **Esc khi đang gõ trong ô tìm kiếm mà ngăn kéo mở**: Esc đóng ngăn kéo, chữ trong ô tìm kiếm giữ nguyên. Test thuộc Task 4.
3. **Dữ liệu realtime đến khi ngăn kéo mở**: nội dung cập nhật, ngăn kéo vẫn mở, vị trí cuộn và lượt đang mở giữ nguyên. Test thuộc Task 4.
4. **Lưu ngay với giá trị dở dang** (đang gõ "7" trong "70"): debounce không lưu giá trị lỗi; rời ô mới báo lỗi. Test thuộc Task 7.
5. **Đổi ngôn ngữ hoặc giao diện khi đang ở cỡ vừa**: các view mount lại vẫn đúng `data-layout`, không mở ngăn kéo rỗng. Test thuộc Task 7.
