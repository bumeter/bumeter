# M3: Skill — Kế hoạch triển khai (bản gọn)

- Spec: `docs/superpowers/specs/2026-09-24-thongke-design.md` (mục 6, 8, 11, 14)
- Wireframe: màn 3 (Skill) và 4 (hộp thoại cài / xác nhận) trong `2026-09-24-thongke-wireframes.md`. Phong cách theo mục 6.0.
- Mục tiêu: màn Skill liệt kê mọi skill, so chi phí nền với mức dùng thật, có danh sách "dùng ở đâu" và gợi ý. Có tắt/bật/cài/gỡ theo 2 bước plan → apply, kèm hoàn tác.
- Nhánh: `feat/m3-skills` (tách từ `feat/m2-dashboard`). Làm theo TDD, mỗi task một commit.

## Dữ liệu thật trên máy (đã kiểm tra)

- Skill cá nhân: `~/.claude/skills/<tên>/SKILL.md` với frontmatter `name` và `description`. Có symlink, ví dụ `pj-clarify` → `~/skills-repo/pj-clarify`.
- `~/.claude/skills/synced/<uuid>/…`: skill đồng bộ từ claude.ai. App **chỉ đọc**, không tắt hay gỡ.
- Plugin: `claude plugin list --json` trả `[{id, version, enabled, installPath, …}]`. `claude plugin details <tên>` trả bảng chữ `component  always-on  on-invoke` (ví dụ `~70  ~6.3k`).
- Khi dùng, skill trong plugin mang tên `<plugin>:<skill>` (ví dụ `superpowers:brainstorming`). Slash command mang tên `/…`.

## Quy tắc chung

- Chỉ thao tác plugin qua CLI `claude plugin`, không tự sửa file cấu hình plugin.
- Mọi thao tác đi qua `plan` (hiện chính xác file bị ảnh hưởng) → `apply` → ghi nhật ký `skill_ops` → có thể `undo`.
- Tắt skill = chuyển sang `~/.claude/skills-disabled/`. Gỡ skill = đưa vào `data_dir/trash/<ts>-<tên>`, giữ 30 ngày. Symlink thì chỉ chuyển hoặc xóa link, **không bao giờ đụng thư mục gốc**.
- Chi phí nền của skill cá nhân là ước lượng: số ký tự của `description` ÷ 3,5. Chi phí mỗi lần gọi: độ dài `SKILL.md` ÷ 3,5. Giao diện ghi rõ "ước lượng".
- Test dùng HOME tạm, và một CLI `claude` giả đặt đầu `PATH`. Không bao giờ chạy trên `~/.claude` thật.

## Review Focus

1. Skill là symlink trỏ tới repo của người dùng → tắt/gỡ/hoàn tác **không bao giờ** xóa hay di chuyển thư mục gốc (Task 4).
2. Gỡ xong rồi hoàn tác, hoặc hoàn tác hai lần → không mất dữ liệu, không lỗi mơ hồ (Task 4).
3. `claude` CLI không có, chậm, hoặc đổi định dạng output → màn Skill vẫn hiện skill cá nhân (Task 2, 5).
4. Tên skill hoặc mô tả chứa ký tự lạ hay `<script>` → hiện dạng chữ (Task 6).
5. Đang có phiên Claude chạy mà skill bị tắt → UI nhắc "có hiệu lực từ phiên mới" (Task 6).
