# Kiro CLI integration — Plan (condensed)

- Data sources: `~/.kiro/sessions/cli/<id>.json` (per-turn metadata, the file is overwritten in full) and `<id>.jsonl` (questions, answers, tools). Turns and questions are joined in order.
- **Kiro does not record token counts.** Context is computed as `context_usage_percentage × context_window_tokens` (explicitly marked as an estimate). Cost is measured in **credits** (`metering_usage`), not converted to $. Models are stored with the `kiro:` prefix so they are not priced using the Claude pricing table.
