Main changes from the current version

  • Skill: keeps the features we just built (cards, toggles, chips, warning label), only switching to the new card language; background-cost unused cards get an orange border. A new "All" chip is added.
  • Settings: grouped into System Settings–style cards (General, Tools, Limits & notifications, Diagnostics). The new "Tools" section shows the log directory and status of each tool. Choose light/dark/system appearance. Thresholds and notification toggles save immediately, with no Save button.
  • Context analysis: the chart, the call breakdown, and suggestions are separate cards; suggestions have colored borders as in Overview.
